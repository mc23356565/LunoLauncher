LunoLauncher

A free, open-source launcher for Minecraft: Java Edition.

Verify your download. Every release publishes the SHA-256 hash of the executable on its release page. The executable is not yet code-signed, so Windows SmartScreen may show a warning; compare the hash before running it.

What it is

LunoLauncher downloads, installs and starts Minecraft: Java Edition. It manages several game folders and versions, installs mod loaders (Forge, NeoForge, Fabric, Quilt, OptiFine), searches and installs mods and modpacks from Modrinth and CurseForge, and signs players in with their own Minecraft account.

Game files, mod loaders and community content are fetched at the user's request from the official sources and public mirrors — the launcher ships without them.

Microsoft account sign-in

Sign-in uses the official Microsoft identity platform flow: OAuth 2.0 device authorization grant (public client, tenant consumers, scope XboxLive.signin), then Xbox Live, then XSTS. The launcher then calls exactly two Minecraft Services endpoints with the player's own credentials:

  • POST https://api.minecraftservices.com/authentication/login_with_xbox — to obtain that player's Minecraft access token;
  • GET https://api.minecraftservices.com/minecraft/profile — to confirm the account owns Java Edition and to read that player's UUID, username and skin.

No other Minecraft Services endpoints are used. Tokens are returned to the player's own device: there is no account backend and no proxy, and tokens are never relayed to any third party.

What it does not do

  • It does not contain, host, mirror or redistribute Minecraft game files.
  • It does not bypass, substitute or weaken Minecraft authentication. Online play requires a genuine Microsoft account that owns Minecraft: Java Edition.
  • It does not collect telemetry or analytics.
  • It is not affiliated with, endorsed by, sponsored by, or otherwise connected to Mojang Studios or Microsoft.

Privacy

The only account data stored is the refresh token, kept on your own machine and encrypted with Windows DPAPI under your Windows user. Deleting the account in the launcher removes it. Nothing is sent to the maintainer.

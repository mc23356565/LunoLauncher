Privacy Policy

LunoLauncher · applies to the current release (v0.1.0) and later versions until replaced

LunoLauncher is a desktop application for Windows. It runs entirely on the user's computer. This policy describes exactly what the application handles, where it is stored, and what leaves the device.

1. Summary

  • No telemetry, no analytics, no advertising identifiers, no crash reporting to the maintainer.
  • There is no account backend and no server operated by the maintainer for user data; the maintainer never receives your account credentials or tokens.
  • The only account data stored is the Microsoft refresh token, on your own machine, encrypted with Windows DPAPI under your Windows user.
  • Deleting an account in the launcher deletes the stored credential from your device.

2. Data stored on your device

  • Account credential. When you add a Microsoft account, the refresh token issued by the Microsoft identity platform is stored locally, encrypted with Windows DPAPI (per Windows user). Access tokens are kept in memory for the session only.
  • Settings. Language, theme, memory, Java path, mirrors, update sources, window preferences and similar options, as plain files in the launcher's data folder.
  • Logs and crash reports. Local text files written only on your device. Nothing is uploaded automatically; exporting a report is an explicit action you take, and the file is yours to send or not send.
  • Game files and content. Minecraft versions, mod loaders, mods, resource packs and worlds that you install, in the folder you choose.

None of the above is transmitted to the maintainer.

3. Network connections

The launcher contacts the following services only to perform the action you requested:

  • Microsoft identity platform (login.microsoftonline.com) — device code sign-in. Microsoft's own privacy statement applies to that interaction: privacy.microsoft.com.
  • Xbox Live and XSTS (user.auth.xboxlive.com, xsts.auth.xboxlive.com) — to obtain the authorisation needed for Minecraft services.
  • Minecraft Services (api.minecraftservices.com) — to sign in, to confirm game ownership and to read your own profile, UUID, username and skin.
  • Mojang / Microsoft download services and public community mirrors (for example BMCLAPI, MCIM) — to download version manifests, libraries, assets and Java runtimes.
  • Modrinth and CurseForge APIs — when you search or install community content.
  • Update sources — the maintainer's signed update manifest, to check for a new version. This request contains no account data.

As with any web request, these third parties receive your IP address and the request itself, and their own privacy policies apply to them.

4. What the maintainer does not do

  • No collection of IP addresses, device identifiers, usage statistics or crash data.
  • No sale, rental or sharing of personal data — there is none to share.
  • No advertising, no third-party trackers, no fingerprinting.
  • No transfer of tokens to any third party, including other launchers.

5. Children

The application is a game launcher. It does not create profiles and does not collect personal data. If you are a minor, use it with the consent of a parent or guardian, and follow the terms of Minecraft and of any server you join.

6. Retention and deletion

Everything listed in section 2 stays on your device until you delete it. Removing an account in the launcher deletes the stored refresh token. Deleting the launcher's data folder removes all settings and local logs. Nothing has to be requested from the maintainer, because the maintainer holds no copy.

7. Your rights

Because the maintainer stores no personal data, requests for access, correction, export or erasure are satisfied by the device: the data is in your own folders. For questions about data handled by Microsoft, Xbox Live or Modrinth/CurseForge, please refer to their respective policies.

8. Security

Tokens are protected with Windows DPAPI, which encrypts them per Windows user account. There is no client secret in the application, and the sign-in uses the public-client device code flow, which never exposes your password to the launcher. Releases publish a SHA-256 hash so you can verify that a downloaded file matches what the maintainer built.

9. Changes to this policy

If a future release changes how data is handled, this page will be updated before that release is published, and the change will be noted in the release notes.
